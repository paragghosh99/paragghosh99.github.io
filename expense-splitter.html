Expense Splitter Tool

Algorithmic expense settlement optimizer minimizing the total number of transactions.

Context

Group expenses often result in multiple redundant transfers between participants. This tool calculates net balances and minimizes the number of transactions required to settle all debts efficiently.

Algorithm Flow

Input Balances

Collect individual contributions and total expense.

Net Calculation

Compute each participant's net payable or receivable amount.

Greedy Matching

Match highest creditor with highest debtor iteratively.

Optimized Output

Generate minimal transaction list for settlement.
