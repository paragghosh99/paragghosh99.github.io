Context

Writing CRUD endpoints is easy. Ensuring the same backend runs reliably across local development, Docker containers, CI pipelines, and cloud deployment is where engineering discipline begins.

This project focuses on production fundamentals: authentication, containerization, automated validation, and real deployment constraints.

Architecture

Client

Sends authenticated requests using Bearer JWT tokens.

FastAPI Layer

RESTful endpoints with dependency injection and validation.

Auth System

JWT-based authentication. Token contains sub (user id) and exp (expiry).

Database

SQLite with SQLAlchemy ORM for persistence.

Container Layer

Docker image ensures consistent runtime across environments.

CI Pipeline

GitHub Actions builds Docker image on every push. Broken builds never deploy.

Engineering Decisions

  • JWT over Session Storage: Stateless authentication simplifies scaling and removes server-side session dependency.
  • Dockerized Workflow: Eliminates “works on my machine” discrepancies by standardizing environment.
  • SQLite Inside Container: Redeploy = fresh container = fresh DB. Intentional tradeoff for demo simplicity.
  • CI First: Every push builds the Docker image from scratch, validating deployability.

Operational Results

✔ Live and accessible via Swagger UI ✔ Docker image reproducible locally and in CI ✔ Authentication and CRUD integration tested with Pytest ✔ Deployment verified on Render cloud platform
