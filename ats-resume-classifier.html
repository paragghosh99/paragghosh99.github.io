ATS Resume Classifier

NLP-driven resume classification system using TF-IDF vectorization and supervised learning.

92% Classification Accuracy
Multi-Class Job Role Prediction

Context

Recruiters often process large volumes of resumes. Automating initial categorization improves efficiency and consistency in candidate screening.

Architecture

Resume Input

Raw text extracted from resume documents.

Preprocessing

Cleaning, tokenization, normalization.

Vectorization

TF-IDF feature extraction.

Model

Supervised classifier for role prediction.

Output

Predicted job category with probability.

Engineering Decisions

  • TF-IDF chosen for interpretability and lightweight deployment.
  • Handled class imbalance through data normalization.
  • Focused on explainability over deep model complexity.
